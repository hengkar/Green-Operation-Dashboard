GitHub Pages Hosting Guide

Deploy this standalone HTML5 dashboard in 60 seconds

Single File Zero-Config Deployment: This HTML5 application requires no build step and no Node server. It is 100% self-contained.

Step 1: Save this file

Save or download this file named as index.html.

Step 2: Push to GitHub Repository

Create a repo on GitHub (e.g. green-ops-dashboard) and commit index.html to the root branch:

git init
git add index.html
git commit -m "feat: Add Green Ops Dashboard landing page"
git branch -M main
git remote add origin https://github.com/<your-username>/green-ops-dashboard.git
git push -u origin main

Step 3: Enable GitHub Pages

  1. In your GitHub repo, click Settings > Pages.
  2. Under Build and deployment > Source, choose Deploy from a branch.
  3. Select branch: main and folder / (root), then click Save.
  4. Your site is live at: https://<your-username>.github.io/green-ops-dashboard/!
